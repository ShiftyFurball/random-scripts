# Random Scripts

A collection of small utilities, browser userscripts, and experiments by ShiftyFurball.

## Scripts

| Project | Description |
| --- | --- |
| [ChatGPT Library Bulk Select](chatgpt-library-select/) | Select or clear loaded image checkboxes in the ChatGPT library. Includes a Tampermonkey userscript and Firefox extension source. |

## Using the userscript

Install Tampermonkey, open `chatgpt-library-select/chatgpt-library-select.user.js`, and paste the full file into a new script. Save it and refresh ChatGPT. Enter library selection mode before using the buttons. Scroll to load additional images and repeat as needed.

The userscript's selection behavior has been confirmed working by its author. Firefox extension packaging has been syntax checked but has not been tested in Firefox.

## Adding scripts

Give each project its own folder with its source and a README explaining installation, usage, and any permissions it needs. Keep credentials and personal data out of the repository.
